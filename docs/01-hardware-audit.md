## Выводы

1. Полный цикл (загрузка → аблитерация → квантование → сервинг) реален на этом ПК
   для dense-моделей до ~14B и MoE до ~30B.
2. Для аблитерации своими руками оптимальны базы 8B–14B (bf16 16–28 ГБ — проходит
   через device_map=auto с выгрузкой части слоёв в RAM).
3. Сервинг — llama.cpp (CUDA) или уже установленная LM Studio; vLLM на Windows
   не рекомендуется (см. docs/02-research.md).
