# Handoffs

Канал общения между параллельными сессиями Claude Code по проекту OAI.
Протокол — скилл `team:handoff-protocol`.

## Правила

1. **Сначала файл.** Задача, решение, статус, находка, приёмка — пишется сюда
   (новый файл или новая секция существующего), коммитится с явным pathspec
   и пушится — **до** любого сообщения.
2. **Сообщение — только уведомление:** 1–3 строки + путь к файлу и хэш коммита.
   Исключения: ack («принято, беру»), вопрос «где ты / ETA», срочный стоп (`P0`).
3. **Закрытие петли:** исполнитель пишет done-handoff обратно, получатель
   независимо проверяет перед приёмкой, reply-handoff закрывает тему.
4. **Не трогать чужие файлы без хэндоффа.** Если нужно изменить то, что ведёт
   другая сессия, — сначала хэндофф.

## Имя файла

`YYYY-MM-DD-<from>-to-<to>-<topic>.md`

## Шаблон

```markdown
# Handoff → <кому> (YYYY-MM-DD): <тема>
> Status: 🔴 TODO / 🟠 PARTIAL / 🔄 IN PROGRESS / ✅ DONE / ⛔ REJECTED / 🔵 DEFERRED
> From: <кто>. Why (business): <одна строка>.

## Кто что делает
| Сторона | Делает |
|---|---|

## Контракт
<точные файлы / команды / имена>

## Задачи + DoD
- [ ] ...

## Границы (чего НЕ делаем)
- ❌ ...

## Ссылки и грабли
```
