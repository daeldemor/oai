# Strata на Mac: пошаговая настройка

Strata — бесплатный движок для больших MoE-моделей на домашнем железе (github.com/Niko1221/Strata). На Mac он работает через Metal и запускает Qwen3.8-Flash-Next, модель примерно на 125 миллиардов параметров. Это заметно умнее всего, что обычно запускают на ноутбуке. После установки модель работает без интернета, а у Strata есть свой чат в браузере.

Одно отличие от моей связки на ПК. У меня на Strata стоит Qwen3.6-35B-A3B в uncensored-версии. На Mac Strata семейство Qwen3.6 не запускает вообще, ни uncensored, ни обычную версию: Mac-движок поддерживает только Flash-Next и Gyro (так написано в документации Strata, `docs/MAC.md` и `docs/QWEN36.md`, и в версии от 17.11.2026 это не изменилось). Обе модели в Mac-версии Strata стоковые, на часть запросов будут отказы. Uncensored-версия Flash-Next от OrcaRouter существует, но её нужно вручную конвертировать из исходников, и работу на Mac для неё никто не описывал, поэтому её в гайде нет.

Если нужна именно Qwen3.6, обычная или uncensored, она запускается на Mac в LM Studio или llama.cpp. Это отдельный раздел в конце гайда.

## Шаг 1. Проверить Mac

Нужен Mac на Apple Silicon (M1 или новее) и macOS 15 или новее. Intel-маки не поддерживаются.

Объём памяти: меню Apple → «Об этом Mac», строка «Память». От него зависит, какую версию модели брать и как быстро она будет работать:

| Память Mac | Что брать | Как работает | Скорость (замеры автора Strata) |
|---|---|---|---|
| меньше 32 ГБ | не рекомендую | Strata стартует только с 16 ГБ, на 16–24 ГБ никто не замерял | — |
| 32–48 ГБ | `q2_0` | модель целиком не помещается, эксперты читаются с SSD | 13–14 токенов/с на M4 Mac mini 32 ГБ |
| 64–96 ГБ | `q2_0` | целиком в памяти | до ~110 токенов/с на M5 Max; на других чипах замеров нет |
| 96 ГБ и больше | `iq3_s` (точнее) | целиком в памяти | ~95–100 токенов/с на M5 Max |

13 токенов в секунду — это примерно скорость чтения вслух, пользоваться можно. Если Mac не из таблицы замеров, скорость будет другой, точных цифр под него нет.

Диск. Модель `q2_0` весит 66 ГБ, плюс помощник для ускорения 1.2 ГБ. На маках с 32–48 ГБ Strata ещё пишет вторую копию экспертов для быстрого чтения с SSD (около 40 ГБ). Итого на 32-гиговом маке нужно около 120 ГБ свободного места, на больших около 75 ГБ. Модель обязательно должна лежать на внутреннем SSD, с внешнего медленного диска будет совсем плохо.

## Шаг 2. Установить Strata

Есть два пути, выберите один.

### Вариант А: приложение (проще)

1. Откройте https://github.com/Niko1221/Strata/releases/latest.
2. Скачайте файл `Strata-…-macos-arm64.dmg` (в имени номер версии, на момент написания 0.2.14).
3. Откройте его и перетащите Strata в «Программы».
4. Запустите Strata из «Программ». Если macOS скажет, что приложение из интернета, нажмите «Открыть».
5. Приложение покажет список моделей и само отметит, какая подходит вашему Mac. Выберите `Q2_0` (или `IQ3_S`, если памяти 96 ГБ+), папку для хранения и дождитесь загрузки.
6. После загрузки откроется чат.

Дальше шаги 3 и 4 не нужны: всё делается в окне приложения.

### Вариант Б: терминал

Откройте «Терминал» (Spotlight → «Терминал») и выполните официальную команду установки:

```bash
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
```

Откройте новое окно терминала и проверьте:

```bash
strata --version
```

Если пишет `command not found`, добавьте папку в PATH и снова откройте терминал:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

## Шаг 3. Посмотреть план (терминал)

Перед загрузкой 66 ГБ полезно проверить, что Strata думает о вашем Mac. Флаг `--plan` ничего не скачивает и ничего не меняет:

```bash
strata launch --model q2_0 --vision off --context 32k --plan
```

Strata напишет, сколько скачивать, хватает ли места и будет ли модель читаться с SSD. Если всё устраивает, переходите к шагу 4. Если не хватает места на диске, освободите его, прежде чем идти дальше.

## Шаг 4. Скачать и запустить модель (терминал)

```bash
strata launch --model q2_0 --vision off --context 32k --save-preset mac-q2 --yes --no-tui
```

Что делают флаги:

- `--model q2_0` — версия модели (на 96 ГБ+ поставьте `iq3_s`);
- `--vision off` — без модуля для картинок, экономит память;
- `--context 32k` — длина контекста. Если памяти 64 ГБ и больше, можно `64k`;
- `--save-preset mac-q2` — запомнить настройки, чтобы потом запускать одной короткой командой;
- `--yes` — не задавать вопросов по ходу;
- `--no-tui` — без экрана мониторинга: команда запустит сервер и вернёт терминал.

Первый запуск качает около 67 ГБ, это надолго. Если связь оборвётся, повторите команду: загрузка продолжится с места обрыва. Потом Strata подготовит модель и запустит её. Когда в терминале появится `Strata is serving.` и адрес `http://127.0.0.1:8080`, всё готово. Следить за работой можно командой `strata monitor --url http://127.0.0.1:8080`.

Дальше запускать так:

```bash
strata launch --preset mac-q2
```

Остановить:

```bash
strata launch --stop --preset mac-q2
```

## Шаг 5. Пользоваться

Чат: откройте в браузере `http://127.0.0.1:8080`.

Модель «думающая»: сначала рассуждает, потом отвечает. Первый ответ после запуска приходит дольше, пока macOS прогревает файл модели.

Если хочется подключить свою программу (Open WebUI, Raycast, плагин для редактора, свои скрипты), у Strata есть OpenAI-совместимый API:

- адрес: `http://127.0.0.1:8080/v1`
- ключ: любой
- список готовых настроек для разных программ: `strata connect`

## Частые проблемы

- **Strata пишет, что модель не помещается в память.** Это предупреждение, а не запрет: на 32–48 ГБ модель и должна читаться с SSD. Если Mac меньше 32 ГБ, работать будет очень медленно.
- **Медленно, меньше 5 токенов в секунду.** Закройте тяжёлые программы, особенно браузер с кучей вкладок: Strata отдаёт под эксперты всю свободную память, и каждый освобождённый гигабайт ускоряет работу.
- **Мало места на диске.** `--plan` из шага 3 покажет, сколько нужно. Помощник для ускорения (1.2 ГБ) можно не качать, добавив `--drafting mtp`.
- **Порт 8080 занят другой программой.** Добавьте к команде `--port 8081` и открывайте `http://127.0.0.1:8081`.
- **Что-то сломалось и непонятно что.** `strata doctor` проверит установку, `strata logs` покажет журнал движка.

## Qwen3.6 на Mac без Strata: LM Studio и llama.cpp

Если нужна та же модель, что у меня (Qwen3.6-35B-A3B), на Mac её запускают в LM Studio или llama.cpp. Это MoE-модель на 35 миллиардов параметров, из которых на каждый токен работает около 3 миллиардов, поэтому на маках она идёт быстро. Она слабее Flash-Next, зато в несколько раз меньше и есть в uncensored-версии.

Версий две:

- обычная, от Unsloth: `unsloth/Qwen3.6-35B-A3B-GGUF`;
- uncensored (heretic, отказы сняты; у меня на ПК 0 отказов из 20 провокационных запросов): `llmfan46/Qwen3.6-35B-A3B-uncensored-heretic-Native-MTP-Preserved-GGUF`.

Обе есть в нескольких размерах (квантах). Какой брать, зависит от памяти. macOS отдаёт видеоядру только часть общей памяти (на маках до 32 ГБ около двух третей, на больших около трёх четвертей), и файл модели вместе с контекстом должен в эту часть поместиться:

| Память Mac | Обычная (Unsloth) | Uncensored (heretic) |
|---|---|---|
| 16 ГБ | `UD-IQ2_M`, 11.5 ГБ, с контекстом не больше 8K; качество заметно хуже | не влезает |
| 24 ГБ | `UD-IQ3_XXS`, 13.2 ГБ | не влезает (самая маленькая версия 17.3 ГБ) |
| 32 ГБ | `UD-Q3_K_XL`, 16.9 ГБ | `Q3_K_M`, 17.3 ГБ |
| 36–48 ГБ | `UD-Q4_K_XL`, 22.4 ГБ | `Q4_K_M`, 21.8 ГБ (как у меня на ПК) |
| 64 ГБ и больше | `UD-Q5_K_XL`, 26.6 ГБ, или `UD-Q6_K_XL`, 31.8 ГБ | `Q5_K_M`, 25.4 ГБ, или `Q6_K`, 29.3 ГБ |

Файлы `mmproj-…` в этих репозиториях нужны только для картинок, качать их не обязательно.

Модель «думающая»: сначала пишет рассуждения, потом ответ. Если в какой-то программе ответы приходят пустыми, поднимите в ней лимит длины ответа (max tokens) до 2048 и выше.

Не запускайте её одновременно со Strata: двум большим моделям памяти не хватит.

### LM Studio (без терминала)

1. Скачайте LM Studio с lmstudio.ai и установите как обычное приложение.
2. Откройте вкладку поиска моделей (значок лупы) и введите `Qwen3.6-35B-A3B`. Для uncensored-версии введите `Qwen3.6-35B-A3B-uncensored-heretic`.
3. Выберите репозиторий из списка выше (`unsloth/…` или `llmfan46/…`), а в нём файл нужного размера из таблицы. Нажмите Download.
4. Когда загрузится, перейдите в чат, сверху выберите модель и при загрузке поставьте длину контекста (Context Length) 32768. Если LM Studio предупреждает, что модель не помещается, возьмите размер поменьше.

Как сервер для других программ: вкладка Developer → Start Server. Адрес `http://127.0.0.1:1234/v1`, ключ любой.

### llama.cpp (терминал)

Установка через Homebrew. Если Homebrew ещё нет (`brew --version` пишет «command not found»), поставьте его командой с brew.sh и выполните команды из блока «Next steps», которые покажет установщик:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install llama.cpp
```

Запуск. Команда сама скачает модель с Hugging Face (в `~/Library/Caches/llama.cpp/`) и поднимет сервер. Обычная версия, размер для мака на 36–48 ГБ:

```bash
llama-server -hf unsloth/Qwen3.6-35B-A3B-GGUF:UD-Q4_K_XL \
  --no-mmproj --alias qwen3.6 \
  -c 32768 -ngl 99 -fa on --jinja \
  --cache-type-k q8_0 --cache-type-v q8_0 \
  --temp 0.7 --top-p 0.95 --port 8080
```

Uncensored-версия, тот же размер:

```bash
llama-server -hf llmfan46/Qwen3.6-35B-A3B-uncensored-heretic-Native-MTP-Preserved-GGUF:Q4_K_M \
  --no-mmproj --alias qwen3.6-heretic \
  -c 32768 -ngl 99 -fa on --jinja \
  --cache-type-k q8_0 --cache-type-v q8_0 \
  --temp 0.7 --top-p 0.95 --port 8080
```

Для другого объёма памяти замените часть после двоеточия на размер из таблицы (`UD-Q3_K_XL`, `Q3_K_M`, `Q5_K_M` и так далее).

Сервер готов, когда появится строка `server is listening on http://127.0.0.1:8080`. Чат открывается в браузере по этому адресу, API для программ: `http://127.0.0.1:8080/v1`. Окно терминала не закрывайте, остановка — `Ctrl+C`. Следующий запуск той же командой возьмёт модель из кэша.

Что значат параметры:

- `-c 32768` — длина контекста. Если загрузка падает с ошибкой памяти (`failed to allocate`), поставьте `16384` или возьмите размер модели меньше;
- `-ngl 99` — все слои на видеоядро;
- `--jinja` — правильный шаблон чата, без него ломаются рассуждения;
- `--cache-type-k/v q8_0` — сжатый кэш контекста, экономит память;
- `--port 8080` — порт. Если он занят (например, Strata), поставьте `8081`.

Если генерация идёт 1–3 токена в секунду, модель не поместилась в долю видеоядра. Помогает размер поменьше или меньший `-c`.

## Что проверено, а что нет

На Mac я ничего из этого не запускал. Раздел про Strata собран по официальной документации Strata (о Mac и об установке) и по моему опыту с ней на Windows; все скорости в таблице — замеры автора Strata на двух маках (M5 Max 128 ГБ и M4 Mac mini 32 ГБ). Команда `strata launch --model q2_0 … --plan` проверена на Windows, на Mac её вывод будет другим.

Uncensored Qwen3.6 я проверял на ПК через Strata и llama.cpp: 0 отказов из 20 провокационных запросов. Имена и размеры файлов в таблице Qwen3.6 взяты с Hugging Face 17.11.2026. Пороги памяти для Qwen3.6 на Mac посчитаны, а не замерены, и скорость на маке я не знаю.
